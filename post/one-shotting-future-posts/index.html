Shiny Object Syndrome

TL;DW: We like novelty, and when it comes to tech, we want to use the shiniest stuff. I think working with enterprise software in C# and Angular has made me realize, this was the shiny thing 20 years ago and 10 years ago, respectively. All shiny things become the shitty old thing, eventually (also see jQuery & React). All you can do is either clean up your own little spot in the codebase. It’s fun to do rewrites for personal projects with 0 DAU but that’s not going to fly in real life.

New Year, New Setup

2 years overdue :) I’m not really sure which setup I was talking about at this time. Not sure what I had in 2024 (maybe a Mac Mini?). I can talk about my setup right now though:

  • Main machine (bigboi): newest machine in my setup. Gift to myself for Christmas 2025
    • Hardware: AMD Ryzen 9 9950X CPU, 64 GB RAM
    • OS: Omarchy (pretty much just Arch Linux with DHH’s dotfiles)
    • Where I do most of my development (for work & outside of work)
  • Laptop (charles-home): got it when I started at Ripple
    • Hardware: 11th Gen Intel Core i7-11800H CPU, 8 GB RAM 😭
    • OS: Windows 11 (still need it for my job, unfortunately)
    • Thin client for my main machine using TailScale
    • Also used for RDPing to Windows machines
      • Usually only when I need to transfer files, though. Otherwise, I just use Remmina on Linux
  • Homelab (acer): where I currently self-host my stuff
    • Hardware: Intel i5-6400 CPU 😭, 16 GB RAM
    • OS: Pop! OS (this used to be my main Linux desktop until I moved to my new machine)
      • I’ve been planning on moving it to NixOS, but it’s hard to migrate OSes when you have running services that other people rely on
    • The only machine with ample storage (3 TB HDD) and has kinda become a data dump
