Recommended Tools for Software Development: Part 1

This one seemed the most interesting to pick for my next article, then I realized that I actually have a draft of this from 2022.

That one only talked about CLI tools, which to no surprise, are still what I use to this day (with some new additions!). I’ll talk about these 3 first, then maybe the new ones for part 2.

From 2022

Git UI: lazygit

This was a real game-changer. I don’t think I can go back to using the VSCode Git UI anymore. Lazygit has all the pros of VSCode Git UI (diff viewing, list staged and unstaged changes) without the cons (slow pushes and pulls, is a GUI). I have it bound to a shortcut in the shell as well, so common tasks take less than 10 keystrokes.

All of this is still true. I’ve even tried moving away from Git to Jujutsu, but lazygit is just too good to let go. Maybe once tooling for Jujutsu has caught up will I consider it again.

Directory jumper: zoxide

“A smarter cd command”

So simple, yet so good. I just do z cd and it takes me to ~/Project/MusicDownloader. It remembers your most visited directories so they’re always the first result to be jumped to, but you can use zi to fuzzy-find all matches.

Command runner: mprocs

Especially useful for web development when you want to start up multiple frontends and a backend server. Just define them in a YAML file and mprocs would spin it up for you (or not, if you have autostart: false)

P.S. I just looked it up to find the couple of PRs I made years ago (#1 and #2), and found out it got renamed to dekit! I’m excited how this is gonna turn out.
