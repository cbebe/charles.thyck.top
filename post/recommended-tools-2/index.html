Open Source Agentic Coding: OpenCode

P.S. I realized I actually mentioned OpenCode in my Self Hosting 2026 Post. I just go into more detail here.

Unfortunately, agentic coding has become a lot harder to ignore. We’ve started using Cursor at work, which can one-shot low-priority tickets that no one was going to bother to do.

It’s gotten good enough that I thought it would be useful for personal projects and actually bought a personal subscription for $30/month. It was a bit annoying to switch back and forth between accounts, and sometimes I would forget to switch and use my work account on a personal project, but it worked for a while.

Eventually, I realized that I don’t use it enough to max out my usage. Towards the end of the month, I would vibeslop a bunch of projects just so I could use up my monthly usage. I found it dumb and wasteful, so I ended my subscription.

I started adopting a “pay as you go” model, where I would use OpenCode’s free tier and connect to DeepSeek API when the when I hit the limit.

Web UI for OpenCode: OpenChamber

OpenCode is good and all, but I wanted the Cursor agent experience, where I can prompt on my phone from anywhere.

I have OpenChamber running on my desktop, and accessible from anywhere through my phone using TailScale.

Ergonomic Keyboard

Not software, but used for software development nonetheless. Even when you’re straight-up hands-off vibeslopping, you still need to type (although maybe not as much).

Working for extended hours outside the house on my laptop actually started to make my wrists hurt. It made me realize how much I take my ergonomic keyboard for granted. Take care of your hands, folks!
